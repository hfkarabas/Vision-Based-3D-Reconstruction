# Prior work and claim boundaries

**Hesaplama Kaynakları Kısıtlı Büyük Ölçekli İHA Görüntülerinde Kalite Geri Beslemeli Bölgesel Adaptif 3B Rekonstrüksiyon**

This recovery implements external-tool orchestration and a bounded controlled experiment. It does not assert a new SfM, MVS, ground filter, terrain mesher, texture algorithm or city-model representation. Its weighted quality score is a transparent engineering heuristic, not a novel mathematical contribution. Final numerical conclusions depend on the executed results in `outputs/mission-omega/research/`.

| Work | Verified reading level | Direct overlap and difference |
|---|---|---|
| [Mostegel, Fraundorfer & Bischof 2018](https://doi.org/10.1016/j.isprsjprs.2018.03.022), [author manuscript](https://elib.dlr.de/120524/1/mostegel2018.pdf) | Abstract, introduction and method sections 3.1–3.2 inspected; not a replication | Prioritizes existing-image depth-map computation using view clusters, coverage and predicted confidence. Omega also schedules existing depth-map work. Omega's post-raster feedback differs from their pre-MVS ranking, but that alone does not demonstrate novelty. |
| [Lim et al. 2021](https://doi.org/10.3390/rs13112118) | Abstract and section 2 inspected | ROI coverage and geometric criteria select image pairs within strips. Omega uses registered sparse-track support on a fixed regional grid; it does not reproduce their strip-based optimization. |
| [Neumann et al. 2025](https://doi.org/10.1007/s11042-025-20596-6), [code/project](https://kai-neumann.github.io/PointCloudMetrics/) | Author project abstract/component summary and repository availability checked; full paper not fully read | RQF already provides local reconstruction feedback for view planning. Omega's raster NoData/edge score is not RQF and cannot be called an exact RQF baseline. The object-digitization benchmark's reference/visibility conditions differ from UAV terrain. |
| [Lou et al., On-the-Fly Feedback SfM](https://github.com/IRIS-LAB-whu/OntheflySfMFeedback) | Repository method overview inspected; publication chronology not independently resolved | Already closes an acquisition/reconstruction/quality/planning loop. Omega fixes captured images and camera poses, schedules offline dense work, and does not plan a new flight. |
| [Ledoux et al. 2021, 3dfier](https://doi.org/10.21105/joss.02866) | JOSS record and source availability checked; no executable trial | Establishes GIS-footprint/point-cloud city-model reconstruction. White LOD1 buildings plus terrain would be a reused representation, not an original contribution. |
| [Stathopoulou et al. 2024 / UseGeo implementation](https://github.com/UseGeoEvaluation/DepthEstimationAnd3DReconstruction) | Official repository scope inspected; no local reproduction | Reinforces stage-specific evaluation and established-backend comparison. Omega's cached COLMAP input is an engineering reuse, not proof of superiority to other backends. |
| [ODM terrain workflow](https://docs.opendronemap.org/arguments/) | Official installation, geolocation and DEM argument documentation inspected | UAV image-derived DTM/DSM/orthophoto is already an established workflow. Omega uses an explicitly named fallback because the required runtime was absent. |

The inherited 147-record file remains a bibliographic screening register. Reading levels above do not inflate it into a systematic review. Earlier foundation claims remain historical and are not upgraded by successful model import.

The executed comparison uses fixed-work budgets, not an asserted identical wall time: two regional actions per arm, four complete 1200×900 reference images per action, three source views per reference, fixed three-iteration settings and ten samples. Complete images are recomputed; only the final merge is tile-limited. Recomputed scores after each action provide the actual feedback loop. Uniform and seeded random controls share the same starting raster and preprocessing policy. Independent bare-earth accuracy is unavailable, and one scene/two actions is insufficient evidence for a general or publishable novelty claim.
