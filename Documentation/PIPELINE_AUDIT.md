# Native reconstruction component audit

Evidence basis: direct inspection of `src/vision3d`, benchmark scripts, III-B/III-C/III-D/III-E reports and the final release report. Historical test counts are reported by those reports, not freshly rerun by this mission. Unit correctness is not independent scientific validation. No files are deleted or replaced during Mission 0.

| Component and source | Established method / assumptions | Correctness and demonstrated evidence | Novelty and disposition |
|---|---|---|---|
| Calibration: `geometry/camera.py`, image loader | Pinhole/OpenCV distortion; EXIF or approximate focal/FOV; centered square pixels when approximate | Resizing/coordinate validations exist; no laboratory calibration or independent distortion validation established. Approximate intrinsics remain a causal uncertainty in III-B | No original calibration method demonstrated. Preserve I/O and provenance, use COLMAP self-calibration as baseline; calibrated settings can be a controlled input |
| Features: `features`, preprocessing | OpenCV SIFT/ORB, cached image descriptors | Detector/matcher compatibility and cache tests; no advantage over COLMAP established | Retain cache and diagnostics for comparison; production default should use established backend |
| Matching: `features/matching.py`, `reconstruction/graph.py` | BF KNN ratio test, optional mutual matching, geometric verification, bounded graph discovery | III-C Rural-80 registers 47/80 across four position clusters; filenames alone are inadequate | Graph-selection experiments are useful engineering, not proven novelty. Preserve as ablations; COLMAP verified matching for baseline |
| SfM: `sequence.py`, `incremental.py`, seed search, map recovery | Incremental essential matrix, triangulation, PnP, landmark filtering | Fresh native Rural-40 28/40; historical fixed Urban 35/40. Independent COLMAP Rural full set now 190/190, a different input scope | No new SfM contribution established. Archive as educational/comparison backend; replace production foundation after visual baseline gate |
| BA: `bundle.py`, `refinement.py` | SciPy least squares, robust loss, fixed gauge anchors, bounded local windows | Local cap normally 5 cameras/400 points; joint BA skipped above 30 poses, capped at 2000 points. Tests do not establish global large-scene accuracy | Replace production optimization with COLMAP/Ceres; retain transactional checks and diagnostics |
| Pair selection: `multiview.py`, `dense_quality.py` | Shared sparse visibility, parallax, bounded references/attempts, optional conditioned selection | III-B removed detached Rural strip but lost footprint; Rural-48 P95 did not improve | Retain diagnostic features and explicit budgets. Conditioning is established geometry, not sufficient novelty |
| Disparity/depth: `stereo.py`, `multiview.py` | Rectification, OpenCV StereoSGBM, bidirectional check, sparse-bounded search, native/recentered canvases | III-E weak canvas had only 289 reciprocal pixels; retry found 145462. Native depth remains fragmented even with COLMAP poses | Replace production depth with established MVS. Preserve CPU implementation as controlled baseline; do not build another MVS engine |
| Consistency: `dense_quality.py`, depth recovery | Relative depth, reprojection round trips, independent camera witnesses, effective disparity gates | III-B/III-C provenance and withheld-view controls expose correlated support; many intersections remain | Retain provenance diagnostics. No proof that current gates outperform mature geometric consistency under matched inputs |
| Fusion: `multiview.py::voxel_fuse` | World-voxel reduction after support filtering; fixed grid optional | Same-grid replay reproduced hashes; coverage depends on threshold and grid origin | Retain repeatable voxel-cell evaluation, replace production fusion with backend fusion unless comparison proves advantage |
| Surface: `stereo.py::surface_triangles`, `surface.py`, `surface_asset.py` | Adjacent depth-grid tessellation, edge caps, cleanup and simplification | Thousands of components and intersections across different source grids; ball pivoting rejected for 28–68% patch-area retention | Replace main surface generation with visibility-aware established mesher. Preserve probes and rejected-experiment evidence |
| UV/texture: `surface_texture.py`, `texture_asset.py`, subdivision | Per-photo UV charts, visibility rays, bounded photographic atlas, fallback color/material | Release photographic area 36.17% Rural-40, 22.77% Urban-40; Blender binding and replay checks pass | Useful prototype and controlled comparison; no new texturing method established. Prefer established texturer if visual evidence supports it |
| Export: `asset_export.py`, `textured_export.py` | GLB/OBJ/MTL/atlas serialization, coordinate conversion, normal handling | Independent Blender imports and hashes in prior reports; format success did not ensure visual usefulness | Retain practical export/provenance utilities; validate adapters on backend meshes |
| Desktop: `demo`, `asset_workflow.py` | Tk orchestration, child workers, Open3D preview, cancel/resume | Real worker and visible Urban navigation tested in III-D; some gestures/Unity unverified | Retain application shell. Backend-neutral job interface; engineering deliverable, not scientific novelty |
| Evaluation: `scripts/audit_*`, DSM comparison, Blender tools | Fixed rays, component/boundary/intersection probes, world-file sampling, photographic coverage | Useful direct evidence against favorable-angle acceptance; DSM alignment and vertical datum limit claims | Retain and strengthen independent metric alignment, full-frame views and immutable inputs |

No component has demonstrated a scientifically original advantage merely by existing or passing tests. The strongest reusable assets are dataset provenance, diagnostic scripts, controlled experiments, export validation, and desktop workflow. Native depth and meshing are the least defensible production components given current visual evidence.

## Comparison controls

The retained Rural and Urban native intrinsics both have original-resolution f=2795.689 px, principal point (2015.5,1511.5), no distortion, and `approximate=True`; their source metadata describes EXIF focal initialization. New independent COLMAP cameras refine f to 2852.135 / 2848.346 px and SIMPLE_RADIAL k to 0.02985 / 0.03293. This is evidence of a calibration-policy difference, not proof that calibration alone caused the native dense failure. Native sparse residuals use processed 1600-pixel imagery; new COLMAP residuals are in original 4032-pixel coordinates. Raw pixel error values cannot be ranked directly.

Historical release numbers: Rural-40 28 cameras, 962839 dense points, 628000 exported faces, 2641 edge-connected GLB components; Urban-40 35 cameras, 1746603 dense points, 1066467 faces, 3525 components. Different reports count raw, optimized or exported topology; never combine them without identifying the representation. Offset-aligned DSM P95 values 11.904 m / 8.306 m are not absolute survey errors.

A full 190-image COLMAP result versus native 40-image release is a practical capability comparison, not an equal-input algorithm comparison. Required scientific controls are (a) same images, independent SfM per backend and (b) same cameras/images, different MVS and meshing stages. Historical crossed-backend experiments already help isolate depth, but do not replace a new accepted textured baseline.

Mission 0 now supplies complete independent full-scene outputs: Rural 190/190 and Urban 161/161 cameras, 1.578 M / 1.292 M fused points. Poisson has 12 / 37 edge-connected components and nominal photographic UV area 98.97% / 96.67%. These are different representations and input sizes from native releases, and UV assignment is not independent texture correctness. Poisson retains positive local intersection probes in 4/8 and 3/8 neighborhoods; raw Delaunay has 527/683 nonmanifold edges and visibly stretched peripheral surfaces. Established software also needs explicit visual/support validation. Full measurements and limitations are in [baseline results](research/BASELINE_RESULTS.md); matched-input/common-footprint superiority remains untested.
